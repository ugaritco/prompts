## Introduction

Ugarit Prompts is a PHP package for adding beautiful and user-friendly forms to your command-line applications, with browser-like features including placeholder text and validation.

Ugarit Prompts is perfect for accepting user input in your [Scribe console commands](https://ugarit.com/docs/scribe#writing-commands), but it may also be used in any command-line PHP project.

## Official Documentation

Documentation for Ugarit Prompts can be found on the [Ugarit website](https://ugarit.com/docs/prompts).
